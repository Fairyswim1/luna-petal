# 루나 페탈 — 달빛으로 엮는 꽃

중학교 1학년 원과 부채꼴을 사용하는 12라운드 조합 퍼즐입니다. 부채꼴을 선택해 중심각 360도와 목표 넓이를 맞추고, 호에 두를 금실 예산을 지킵니다. 여분 조각은 남깁니다.

## 실행

Node.js 22 이상에서 `npm test`, `npm run build`, `npm start`. 런타임 설치 의존성은 없습니다. Vercel에서 이 저장소를 Import하면 vercel.json으로 단독 빌드됩니다.

## 기록과 범위

튜토리얼은 실제 진행에서 분리됩니다. 12개 꽃 수집과 진행을 브라우저에 저장합니다. 새 상황 8개 과제는 첫 응답·도움·재시도·설명과 검토 기록을 구분하고 읽을 수 있는 HTML로 내보냅니다. 기기 간 계정 동기화는 없습니다. 게임 승리는 성취기준 이수 판정이 아닙니다.

도형은 SVG, 수식은 번들 KaTeX, 주요 에셋 6개는 내장 이미지 생성으로 제작했습니다. 서체·KaTeX 라이선스는 theme과 vendor에 포함합니다. 원문 교과서 및 추출문은 포함하지 않습니다.
